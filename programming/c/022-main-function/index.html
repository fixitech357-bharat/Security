Foundation

What Is main()?

Every complete executable C program requires at least one function, called main, which is where execution begins. You do not have to explicitly declare main, though you do need to define it. The return type for main is always int.

When you run a C program, the operating system calls a small piece of startup code (in a file like crt0.o on Unix systems) whose job is to find the arguments for main and call it. So main is not actually the first code that runs — but it is the first code you write that runs.

🚫
Can't Be static
main has external linkage. It must be callable from the startup code.
🚫
Can't Be inline
In a hosted environment, the inline specifier shall not appear on main.
🚫
Address Can't Be Taken
You cannot use &main. The compiler treats main specially.
⚠️
Shouldn't Call Itself
Recursive calls to main are legal but unusual and generally discouraged.

Exit Status

What Does main() Return?

The return value from main indicates the program's exit status. The operating system and any calling scripts can read this value to know whether the program succeeded or failed.

✅
return 0; (Success)
The conventional way to signal successful execution. EXIT_SUCCESS is also valid.
❌
return 1; (Failure)
Indicates an error. Any non-zero value signals failure. EXIT_FAILURE is also valid.
⚠️
No return statement
In C99 and later, reaching the closing } of main is equivalent to return 0;.
📜
C89 behavior
In C89, if main ends without a return, the exit status is undefined. Always return explicitly.
💡
How to check: On Linux/macOS, run your program then type echo $? to see the exit status. On Windows, type echo %ERRORLEVEL%. A value of 0 means success.

Command-Line

How argc and argv Work

When you run a program from the terminal, you can pass extra information as command-line arguments. main receives these through two parameters: argc and argv.

🔢
argc
An integer — the number of command-line arguments, including the program name. Always at least 1.
📋
argv[0]
The name of the program as typed on the command line.
📥
argv[1] … argv[argc-1]
The actual arguments passed to the program, as strings.
🛑
argv[argc]
A null pointer. Marks the end of the argument array.
Example Command
$ ./myprogram hello world
Then argc = 3, argv[0] = "./myprogram", argv[1] = "hello", argv[2] = "world"

What You Just Learned

main() is the entry point of every C program. Here's the summary:

Entry Point
main() is where execution begins. The OS startup code calls it first.
Always Returns int
The return type is always int. return 0; means success.
Three Signatures
void, argc/argv, or the non-standard envp form.
Command-Line Ready
