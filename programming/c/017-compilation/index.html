🔧 1. Preprocessing
The preprocessor handles all lines starting with #. It pastes in the contents of included headers (#include), replaces macros (#define), and removes comments. The output is a pure C file — no # lines left — called the translation unit.
$ gcc -E main.c -o main.i

What You Just Learned

The compilation process turns human-readable C code into machine-executable binaries. Here's the summary:

Preprocessing
Handles #include, #define, and comments. Produces a pure C file.
Compilation
Translates C into assembly language. Checks syntax and types.
Assembly
Turns assembly code into machine code (object file .o).
Linking
Combines object files with libraries into a single executable.
