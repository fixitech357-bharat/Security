Recap

What You Just Learned

C has evolved carefully over 35+ years. Here's the summary of each standard and why it matters:

C89 / C90
The first official standard. Defined the language and unified existing practice.
C99
Added // comments, long long, VLAs, designated initializers, and more.
C11
Added multi-threading, _Generic, _Static_assert, and alignment support.
C17
A bug-fix release. No new features — just defect fixes and deprecated features.
C23
Latest standard. Added nullptr, typeof, binary literals, and removed old-style functions.
